# Twilight Princess Web Port

[Not fully created by me](https://github.com/caribbeansc/dusklight) but I re-did the UI to make it look / function a bit better.

Also putting it here pre-built so that the layout for files and such are clear.

# How to run this Port

- Locally

To run this port locally you should use the StartLocalHost.py to ensure that the SharredArrayBuffer will work / be active.

- From Domain / URL / Etc.

To run this anywhere else just place the files in the directory of where ever you wish to host the game and open the link to the HTML.
